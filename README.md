# 🇬🇧 English

## 📖 About the Project

**Workshop Manager** is an ongoing full-stack web development project designed to simplify the organization and management of workshops.

The goal is to create an application where workshops can be organized, displayed, and managed, with registration functionality planned as part of the development process.

The frontend and backend are partially functional, and development is ongoing.

> 🚧 **Work in Progress:** Some parts of the application are already functional, while others are still being implemented or planned.

## 🛠️ Technologies

**Frontend**
- React
- JavaScript
- HTML5 & CSS3
- Vite

**Backend**
- Node.js
- Express.js
- REST APIs

**Database**
- PostgreSQL

**Development Tools**
- Git & GitHub
- Visual Studio Code

**Workshop Manager** ist ein Full-Stack-Webentwicklungsprojekt, das sich derzeit in der Entwicklung befindet.
